MobTime puts the [mobti.me](https://mobti.me) timer in a tool window inside IntelliJ-based IDEs. The rotation stays in the editor instead of another browser tab. When a turn ends, the plugin raises an alert from the page title.

It is a Java plugin on the JetBrains Marketplace. It needs JCEF, which has shipped with IntelliJ since 2020.2. The source is public.
