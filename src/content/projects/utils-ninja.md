Utils Ninja is a browser tab for the small chores that break a coding session. Format some JSON, encode a string, turn a curl command into fetch, look up a status code, convert a timestamp.

It is meant to be fast and accessible: open it, use the tool, leave. The app is Vue and TypeScript, and the source is public.
